# 발표 포인트 — 고려 → 발견 → 선택 → 효과

각 항목은 **"저희는 이걸 고려했고, 이런 걸 발견했고, 그래서 이렇게 선택했습니다"** 구조다.
심사위원이 물어볼 질문을 **먼저 답해버리는 것**이 이 구조의 목적이다.

> ⚠️ 2번·3번은 팀 결정(baseline 정의 · 메인 KPI)이 확정돼야 멘트가 고정된다. 나머지는 지금 확정 가능.
>
> ⚠️ **법령·고시 인용 전부 미검증.** 고시 번호(제2019-16호), 상한 비율(30%), 산정식 `min(추가비용, 편익×30%)`, 서식명(별지 제3호)은 **모두 디자인 목업에서 가져온 값**이다. 발표에서 조문을 말하려면 아래를 먼저 확인할 것.
>
> 1. 국가법령정보센터 — 「지속가능 교통물류 발전법」제21조
> 2. 국토교통부 고시 현행본 — 번호·개정일·산정식·상한
> 3. 한국철도물류협회 전환교통 지원사업 공고 — 산정식·서식·지원 단가
>
> 틀린 조문을 발표에서 말하면 즉시 신뢰를 잃는다. 확인 못 하면 **조문 번호를 빼고 제도명만** 말하는 쪽이 안전하다.

## 1. 최저톤수 — "왜 중소기업은 철도를 못 쓰는가" ⭐ 가장 강함

**고려**
소량 화물이 철도로 안 가는 이유를 "화주가 관심이 없어서"로 두면 서비스가 성립하지 않는다. 진짜 이유를 찾아야 했다.

**발견**
코레일 화물운임에는 **톤수 하한**이 있다.

```
운임계산톤수 = max(실제 적재톤수, 화차표기하중톤수 × 품목별 최저톤수율)
```

최저톤수율은 품목별로 **30~100%** 차등된다. 18톤 화차에 6톤만 실어도 최저톤수(예: 80% = 14.4톤) 기준으로 요금을 낸다.
→ 중소기업은 철도를 쓰고 **싶어도 못 쓴다.** 관심의 문제가 아니라 **제도의 문제**다.

**선택**
합적으로 최저톤수를 나눠 낸다. 화주 4곳이 각자 화차 1량씩 잡으면 최저톤수를 4번 내지만, 1량에 합치면 1번이다.
시드 기준 **철도 단독 배차 대비 67% 인하**가 나온다.

**효과**

- "왜 지금까지 아무도 안 했나"에 대한 답이 된다
- 절감의 근거가 마케팅 수치가 아니라 **제도 구조**가 된다
- 코레일 입장에서도 공차가 채워지므로 양쪽이 이득 — 선순환 BM의 근거

> **멘트:** _"저희는 중소기업이 철도를 안 쓰는 게 아니라 못 쓴다는 걸 발견했습니다. 코레일 화물운임은 실제 적재량이 아니라 화차 정원에 품목별 최저톤수율을 곱한 값을 하한으로 부과합니다. 6톤을 보내도 그만큼을 못 채우면 하한 요금을 내야 합니다. 저희는 이걸 합적으로 풀었습니다."_

### ⚠️ 여기서 절대 헷갈리면 안 되는 것 — 최저"운임"과 최저"톤수"는 다른 제도다

자체 검증에서 **우리가 처음에 이 둘을 뭉쳤다.** 심사위원이 아는 사람이면 바로 걸린다.

| | 내용 | 우리 노선(428km)에 |
| --- | --- | --- |
| **최저운임** | "화차표기하중톤수의 **100km에 해당하는** 운임" → **거리 하한** | ❌ 무관 (100km 초과) |
| **최저톤수** | `max(실적재톤수, 정원 × 품목별 최저톤수율)` → **톤수 하한** | ✅ 이게 우리 근거 |

최저운임은 *"100km 미만을 가도 100km로 계산한다"* 는 뜻이라 장거리 간선에는 구속력이 없다.
**발표에서 100km 조항을 근거로 들면 안 된다.**

**그리고 최저톤수율을 100%라고 말하면 안 된다.** 실측 분포상 율>0인 597개 품목행 중
100%는 194행(**32.5%**)뿐이고 403행(67.5%)이 100% 미만이다. 우리 계산도 처음엔 100%로 두어
과금톤수를 과대추정하고 있었고, 중앙값 80%로 낮춰 잡았다.

> **질문 나오면:** _"최저톤수율은 품목별로 30에서 100%까지 차등됩니다. 저희는 공개 데이터 실측 분포의 중앙값인 80%를 기본값으로 썼습니다. 100%로 두면 저희에게 유리하게 나오지만 그건 전체 품목의 3분의 1에만 해당해서요."_

### 1-1. 공차는 도로에도 있다 — 물류 이해도 증명용 (질문 나오면)

배출계수를 유류 소비량으로 교차 검증하다 발견한 것.

| 기준                               | 배출원단위        |
| ---------------------------------- | ----------------- |
| 편도 만재만                        | 34.7 g/ton·km     |
| **왕복 (갈 때 만재 / 올 때 공차)** | **57.8 g/ton·km** |
| + 평균 적재율 50%                  | 115.6 g/ton·km    |

트럭도 갈 때만 싣고 **올 때는 빈 채로 온다.** 그래서 실제 배출원단위가 만재 기준의 1.7배가 된다.
→ 공차는 철도만의 문제가 아니라 **화물운송 전체의 구조적 문제**이고, 우리는 그중 철도 쪽을 푼다.

> **멘트:** _"배출계수를 유류 소비량으로도 교차 검증했습니다. 그 과정에서 트럭도 올 때는 빈 차로 온다는 걸 반영해야 한다는 걸 확인했고, 계수에 어느 기준인지를 명시해뒀습니다."_

## 2. baseline 선택 — "불리한 결과를 숨기지 않았다"

**고려**
편익을 계산하려면 "도로로 갔다면 얼마였을까"를 정해야 한다. 그런데 이걸 뭘로 잡느냐에 따라 결과가 뒤집힌다.

**발견**
같은 화물·같은 거리·같은 계수인데 baseline 정의만 바꾸면 전환 추가비용의 **부호가 뒤집힌다.**

| baseline                     | 추가비용 A | 보조금    |
| ---------------------------- | ---------- | --------- |
| 화주 실지불 운임 (전세 트럭) | 음수       | 대상 아님 |
| 만재 트럭 표준운임 환산      | 양수       | 발생      |

**선택** — ⚠️ **아직 확정 못 함. 고시 원문 확인 필요**

기존에 "고시 문구가 '기존 도로 운송 실적 기준'이라 실지불을 택했다"고 적었으나, 그 문구는 **디자인 06c 추가비용 표의 셀 라벨**이지 법령 문구가 아니다. 근거로 쓸 수 없다.

baseline 정의는 아래를 확인한 뒤에 정한다.

1. 국가법령정보센터 — 「지속가능 교통물류 발전법」제21조
2. 국토교통부 고시 **현행본** — 번호·개정일·산정식·상한 비율
3. 한국철도물류협회 전환교통 지원사업 **공고** — 산정식과 실제 서식이 붙어 있을 가능성이 높다

확정 전까지는 **보조금이 0으로 산정되는 케이스를 화면에 그대로 표시한다**는 원칙만 유지한다.

**효과**

- 유리한 baseline을 골라 숫자를 키우지 않았다는 게 그대로 드러난다
- "이 숫자 어떻게 나온 거냐"는 질문에 산식과 근거 조문으로 답할 수 있다

> **멘트:** _"도로 운임을 뭘로 잡느냐에 따라 보조금이 나오기도 하고 안 나오기도 합니다. 저희는 고시 문구가 '실적 기준'이라 실지불 운임을 택했고, 그 결과 보조금이 0원으로 나오는 경우도 화면에 그대로 띄웁니다."_

## 3. 보조금과 절감을 동시에 주장하지 않는다 — 예상 질문 선점

**고려**
"운송비도 절감되고 보조금도 받는다"는 가장 팔기 좋은 문구다. 그런데 검산해보니 성립하지 않았다.

**발견**
전환교통 보조금 = `min(전환 추가비용, 사회환경적 편익 × 30%)`
→ 철도가 도로보다 **싸면** 전환 추가비용이 없다 → **보조금 대상이 아니다.**
"철도가 더 싸다"와 "보조금을 받는다"는 **산식상 동시 성립이 불가능**하다.

**선택**
세그먼트를 나눴다.

|                          | 도로 단가          | 우리가 파는 값                                     |
| ------------------------ | ------------------ | -------------------------------------------------- |
| **소량 화주** (중소기업) | 전세 트럭이라 비쌈 | 합적으로 철도 진입 가능 + 도로보다 저렴 + ESG 자산 |
| **대형 화주**            | 만재라 이미 저렴   | 전환 추가비용을 보조금이 보전 + ESG 자산           |

**효과**

- _"철도가 싸다면서 왜 보조금을 받냐"_ 는 질문을 무력화한다
- 두 세그먼트에 파는 값이 다르다는 게 BM의 정교함으로 읽힌다

> **멘트:** _"운송비 절감과 보조금을 같이 말하는 서비스가 많은데, 고시 산식상 둘은 동시에 성립하지 않습니다. 철도가 싸면 추가비용이 없어서 보조금 대상이 아니거든요. 저희는 세그먼트를 나눴습니다."_

## 4. AI는 숫자를 만들지 않는다 — 환각 방지 ⭐ 생성형 AI + 구현 수준 동시 방어

**고려**
보조금 사업계획서는 관할 지자체에 **실제로 제출하는 법정 서식**이다. 여기에 AI가 지어낸 숫자가 들어가면 서비스가 끝난다.

**발견**
LLM에게 "표를 보고 요약해줘"라고 하면 숫자를 그럴듯하게 바꿔 쓴다. 서식 문서에서는 치명적이다.

**선택**
아키텍처로 분리했다.

- **수치** — 전부 법정 산식으로 결정적 계산. LLM 개입 경로 자체를 차단
- **문장** — 계산된 수치를 입력으로 넣고 **서술만** 생성
- **검증** — 생성된 문장에서 숫자를 전부 추출해 입력에 없는 값이 있으면 **자동 재생성**

**효과**

- _"AI가 숫자를 지어내면 어떡하냐"_ 에 한 문장으로 답한다
- 화면 하단 고정 문구 "수치는 법정 산식으로 계산되며, AI는 서술 문장만 작성합니다"가 카피가 아니라 **실제 구현**이라는 증명

> **멘트:** _"제출용 서식이라 AI가 숫자를 지어내면 끝입니다. 그래서 수치는 전부 법정 산식으로 계산하고 AI는 문장만 씁니다. 생성된 문장에서 숫자를 뽑아 입력에 없으면 다시 쓰게 하는 검증기까지 넣었습니다."_

## 5. 계수는 한 파일에, 출처와 버전을 박아서 — 검증 가능성

**고려**
심사 중 _"이 계수 어디서 나온 거냐"_, _"작년 신청서와 숫자가 왜 다르냐"_ 가 나온다.

**발견**
배출계수·사회적비용 원단위는 **매년 고시로 바뀐다.** 계산 로직에 숫자를 흩어놓으면 교체가 불가능하다.

**선택**

- 모든 계수를 `constants.ts` **한 파일**에만 둔다. 계산 로직에는 숫자 리터럴이 없다
- 계수마다 **출처를 명시**하고, 미검증 값은 `VERIFIED = false` 로 표시한다
- 계산 결과에 **계수 버전**을 박아 서식에 인쇄한다

**효과**

- 심사 중 수치 교체 요구가 들어와도 한 곳만 고치면 전체가 갱신된다
- 계수 출처가 서식에 그대로 찍혀 나온다

## 6. 현장 네트워크를 안 믿는다 — 폴백 (물으면 답하는 용도)

AI 호출부마다 규칙기반 폴백을 뒀다. Claude 호출이 실패해도 템플릿 문장으로 대체되고 화면은 그대로 뜬다. 배지만 `fallback` 으로 바뀐다.

> 발표에 넣기보다 **질문이 나왔을 때** 답하는 용도.

## 발표 순서 제안

1. **문제** — 최저톤수 (포인트 1). 여기서 "못 쓴다"를 각인
2. **해결** — 합적으로 최저톤수 분할 → 시연
3. **정직성** — baseline 선택과 보조금 0 표시 (포인트 2·3)
4. **AI** — 조율 에이전트 + 환각 방지 (포인트 4)
5. **구현** — 계수 관리 (포인트 5)

> 1번을 초반 30초 안에 못 박는 게 제일 중요하다. 이게 안 박히면 나머지가 전부 "있으면 좋은 기능"으로 들린다.
