# 알뜰철도 X — 작업 인수인계

새 대화에서 이어서 작업할 때 이 문서를 첨부하세요.

## 프로젝트

전환교통 보조금 · ESG 공시를 다루는 B2B 물류 웹앱. 해커톤 출품작.
소량 화물을 AI로 합적해 코레일 빈 화차에 매칭하고, 그 실적을 보조금 신청서와 K-ESG 지표표로 환산합니다.

브랜드: **알뜰철도 X** · 태그라인 "철도를 채우는 순간, ESG가 완성됩니다"

타이포 규칙
- 숫자가 큰 값일수록 자간을 좁힘: 68~116px는 `-0.05em`, 28~42px는 `-0.035em`, 17px는 `-0.02em`
- 모든 수치에 `font-variant-numeric: tabular-nums`
- 라운드: 버튼 14px, 카드 18~20px, 배지 8px, 알약 999px, 문서 용지 6px
- 그림자: 카드 `0 12px 40px rgba(25,31,40,0.10)`, 문서 `0 8px 28px rgba(25,31,40,0.07)`

레이아웃
- 로그인 후 화면: 좌측 사이드바 240px + 여백 32 + 콘텐츠 1200px = 전체 1504px
- 사이드바 메뉴: 홈 / 화물 / 매칭 / 보조금 · ESG 리포트 / 정산, 하단에 설정 + 프로필
- 로그인 전 랜딩(01)만 상단바

## 조율 에이전트 (04c~04e) — 이 프로젝트의 차별점

매칭이 실패했을 때 화주별 제약을 자연어로 해석해 조정 가능 항목을 찾고, 화주마다 다른 설득 문장을 써서 편성을 살립니다. 최적화 알고리즘으로는 못 하는 부분이라 생성형 AI가 필요한 이유가 됩니다.

시나리오: 한림케미칼 2일 연기 요청 → 조건부 수락(1일까지) → 1일로 재제안 → 수락 / 우진산업 물량 당김 → 수락 / 남광유화 인도역 변경 → **거절**(추가 트럭 운임 4,300만 > 절감 2,600만). 거절 케이스를 남겨 두는 게 핵심입니다.

## 문서 화면(06c) 표기 규칙

- **자동 산출 수치**: 회색 산식 배지 `#F2F4F6` / `#6B7684`, 편집 불가, 계수 출처를 별도 열에 표기
- **AI 서술 문장**: 좌측 파란 바 3px `#3182F6` + 배경 `#F5F9FF`, 상단에 "AI 서술 · 편집 가능" 라벨, hover 시 우측 상단에 "↻ 문단 재생성" (전체 테두리 + 하단 배지 방식은 폐기)
- 문서 상단 안내: "수치는 법정 산식으로 계산되며, AI는 서술 문장만 작성합니다."
- 표는 관공서 서식처럼 `1px solid #B0B8C1` 외곽 + `#D1D6DB` 내부선 + `#F2F4F6` 헤더
