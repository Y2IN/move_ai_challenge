## 2. 계산식 — 협회 별지 제3호 서식 원문

출처: 한국철도물류협회 2026년 사업계획서 작성안내(붙임2) 별지 제3호 서식 「보조금 신청총액 산출내역서」 및 별지서식 XLSX(붙임4)
링크: http://www.klaru.co.kr/sub/traffic/notice.asp?mode=view&bid=5&idx=335&page=1

### 2.1 신청액 계열

```
A  수단전환 추가비용 = 철도운송비용 − 도로운송비용

     철도운송비용 = 출발지 셔틀운송비 + 상하역비 + 조작료 + 보관비
                  + 철도운송비
                  + 도착지 셔틀운송비 + 상하역비 + 조작료 + 보관비
     도로운송비용 = 협약물량(톤) × 도로운송거리(km) × 도로운임(원/톤·km)

B  철도보조금 단가 = A ÷ 철도역간거리(km) ÷ 협약물량(톤)          [원/톤·km]
C  보조금 신청기준액 = 철도역간거리 × 협약물량 × B                 (수치상 A와 동일)
```

### 2.2 상한액 계열 ⭐ 여기가 자주 틀림

```
D  도로운송 시 사회·환경적 비용 = 협약물량 × 도로운송거리 × 123.09원
F  철도운송 시 사회·환경적 비용 = (협약물량 × 철도거리   × 42.25원)
                               + (협약물량 × 셔틀거리   × 123.09원)   ← 셔틀은 도로 원단위

G  보조금 상한액 = (D − F) × 30%
```

**틀리기 쉬운 지점 두 개**

1. **30%는 "편익 총액"이 아니라 "절감액(D − F)"에 곱한다.** 편익 총액에 곱하면 과대 산정.
2. **셔틀 구간은 도로 원단위(123.09)로 철도 측(F)에 가산한다.** 빼먹으면 절감액이 커져 상한이 과대 산정.

### 2.3 최종

```
H  보조금 신청총액 = min(C, G)
   ※ 공고 부기: "작은금액 이하로 전략적 신청 가능"
      → 신청액을 min 값보다 낮게 적는 것이 허용됨
      → 사업효과 지표 I = G / H 가 심사 배점 40점이라, 낮게 적을수록 효과 지표가 좋아짐
```

### 2.4 사회·환경적 비용 원단위 (연도별)

| 연도 | 도로 (원/톤·km) | 철도 (원/톤·km) |
|---|---|---|
| 2024 | 110.78 | 38.03 |
| 2025 | 116.94 | 40.14 |
| **2026** | **123.09** | **42.25** |

### 2.5 컨테이너 톤수 환산

### 2.6 도로운임 baseline — 하이브리드 ⭐

2026년부터 **안전운임제 적용 품목은 고시 표준운임 강제**입니다. 실지불 실적이 아닙니다.

> "안전운임제 재시행(`26.2.1.)에 따라 국토교통부가 고시한 안전운임제가 적용되는 화물의 경우
> 출하지 또는 도착지가 소재한 행정구역(항만 포함) 간의 안전운임제의 운임과 거리를 적용한다."

- 왕복운임 고시 구간의 편도 도로운송비 = **고시 안전운임 ÷ 174 × 100**

- 적용 대상: 수출입 컨테이너 · 시멘트

→ 우리가 논쟁했던 "실지불 vs 표준운임"의 답: **품목에 따라 갈린다.** 안전운임 품목은 표준운임, 그 외는 실적.

## 3. 코레일 화물운임 — 두 개의 하한을 구분할 것 ⚠️

### 3.1 최저운임 = 거리 하한 (톤수 규칙 아님)

코레일 공식 안내 원문:

- 일반화물: "화차표기하중톤수의 **100km에 해당하는** 운임"
- 컨테이너화물: "규격별, 영공별 **100km에 해당하는** 운임"
- 보조차·갑종철도차량: "자중톤수 100km 운임"

→ 실질은 **"운행거리가 100km 미만이어도 100km로 계산"** 하는 거리 하한입니다.
**100km 초과 구간에서는 구속력이 없습니다.** 울산→오봉(428km)에는 적용되지 않습니다.

### 3.2 최저톤수 = 톤수 하한 (별개 제도)

```
운임계산톤수 = max(실제 적재톤수, 화차표기하중톤수 × 품목별 최저톤수율)
```

품목별 최저톤수율(LWST_TON_RT)이 **30 / 50 / 60 / 70 / 80 / 90 / 95 / 96 / 100 %** 로 차등됩니다.

| 최저톤수율 | 행 수 |
|---|---|
| 100% | 194 |
| 96% | 11 |
| 95% | 2 |
| 90% | 42 |
| 80% | 142 |
| 70% | 50 |
| 60% | 151 |
| 50% | 1 |
| 30% | 4 |
| 0 (미적용) | 264 |

**율 > 0 인 597행 중 100%는 194행(32.5%)뿐이고 403행(67.5%)이 100% 미만입니다.**

https://www.data.go.kr/data/15134364/fileData.do

**단서 (중요)**

- 품목코드가 유일키가 아닙니다. 597개 코드 중 **167개(28%)가 서로 다른 복수의 값**을 가지며,
  CSV에 시행일자·화차종별 구분 컬럼이 없어 현행값을 특정할 수 없습니다.

  원문을 확보하지 못했습니다. 코레일 사규 페이지 HTTP 500.

### E-7-1 대기오염물질 배출량 — 요구 단위는 **배출농도**

가이드라인 원문 [데이터산식] (p.74):

> "대기오염물질 배출 = 질소산화물, 황산화물, 미세먼지의 **배출농도(PPM, mg/㎥)**"

**확인 실패:**

- 도로 123.09원/톤·km, 철도 42.25원/톤·km 원단위의 1차 산출 근거 문헌(한국교통연구원 연구보고서 등)을 특정하지 못했다. 작성안내는 '대기오염·온실가스·소음·사고·혼잡비용을 포함하여 산출'이라고만 하고 출처 문헌·기준연도를 밝히지 않는다. 리포트에 coefficientVersion을 박으려면 이 출처를 별도로 확보해야 한다.
- g-CO2/ton·km 형태의 개별 온실가스 배출계수는 이 사업 서식에 존재하지 않는다. 통합 사회·환경비용 원단위(원/톤·km)만 쓴다. CO2 감축량(co2ReducedTon)을 리포트에 별도로 쓰려면 전환교통 사업 서식이 아닌 다른 출처(국가 온실가스 배출계수 등)를 근거로 삼아야 하며, 그 경우 '전환교통 고시 근거'라고 표기하면 안 된다.
- 고시 제17조제3항의 '상한액'을 30%로 정한 협약기관의 내부 결정 문서 또는 국토교통부 지침 원문을 확보하지 못했다. 30%는 연도별 모집공고·작성안내에서만 확인된다. 협회 홈페이지에는 '국토교통부 지침에 의거 수시 변동될 수 있음'이라는 단서가 붙어 있어, 30%는 법정 고정값이 아니라 연도별 변동 가능한 운영값으로 보아야 한다.
- 추가비용 A(= 철도운송비용 − 도로운송비용)가 음수인 경우(철도가 도로보다 싼 경우)의 처리 규정을 명문으로 찾지 못했다. 고시·공고·작성안내 어디에도 음수 처리 조항이 없다. 실무상 신청 자체가 성립하지 않는 것으로 보이나 확인되지 않았다.
- 「2026년 적용 화물자동차 안전운임 고시」(국토교통부고시 제2026-55호 추정)의 고시 원문 및 운임표를 직접 열람하지 못했다. 고시번호는 NLIC 2차 자료 기준이다. 도로운임을 실제로 계산하려면 이 고시의 거리별·품목별 운임표가 필요하다.
- 2026년 모집공고의 선정 결과(협약사업자 명단, 실제 집행액)는 확인하지 못했다. 접수 마감이 2026.7.20이고 발표는 마감일로부터 15일 이내이므로 2026.8.4경 발표되었을 것으로 보이나 협회 공지사항에 게시물이 없다.

**확인 실패:**

- 「대기환경보전법 시행규칙」 별표1 대기오염물질의 정확한 종수 — K-ESG v2.0은 '64개'라고 기술하나 법제처 국가법령정보센터 현행 원문(별표1)을 직접 확인하지 못함(조회 시점 서버 장애). 인용 시 법령 원문 재확인 필요.
- E-7-1의 세 번째 대상 물질이 PM2.5인지 TSP인지 — K-ESG v2.0 문서 내부가 불일치(p.74 성과점검 '미세먼지(PM2.5)' vs p.75 추가설명 '먼지(TSP)'). 실무상 어느 값을 입력해야 하는지는 한국생산성본부 지속가능경영본부(sm@kpc.or.kr / 02-398-6432) 유권해석 필요. 안전한 대응은 TSP·PM10·PM2.5를 모두 병기하는 것.
- k-esg.org 자가진단 시스템(온라인 진단도구)의 E-7-1 입력 필드가 실제로 어떤 단위·물질 조합을 받는지 — 시스템 UI를 확인하지 못함. 현재 금액(원)을 입력 중이라면 그 칸이 정말 E-7-1인지, 혹은 다른 항목(예: 환경 투자비 성격의 사내 커스텀 필드)인지 먼저 확인 권장.
- 국립환경과학원 「Scope 3 온실가스 배출량 산정 및 보고 가이드라인(v1.0)」의 정확한 발간일·원문 PDF 및 Category 4 국내 표준 배출계수(kgCO2eq/톤-km) 수록 여부 — 배포처 서버 접속 불가로 미확인. 국내 화물운송 수단별 공식 배출계수(국토교통부·국가 LCI DB·한국교통연구원 등)의 현행 값도 이번 조사 범위에서 확정하지 못함.
- IFRS S2 산업기반 지침(Industry-based Guidance, SASB 기반)의 'Air Freight & Logistics' / 'Road Transportation' / 'Marine Transportation' 업종에서 NOx·SOx·PM 정량 지표를 요구하는지 여부 — 업종별 부속지침 원문 미확인.
- 한국 KSSB(한국지속가능성기준위원회) 지속가능성 공시기준 제1호·제2호의 확정·의무화 일정과 K-ESG 가이드라인과의 연계 여부 — 이번 조사 범위 밖.
- K-ESG '공급망 대응 가이드라인'(2023-02-14 게시)에서 대기오염물질 항목의 요구 단위가 v2.0 본편과 동일한지 — 원문 미확인. 대기업 고객사가 협력사 평가에 이 문서를 쓰는 경우 별도 확인 필요.
